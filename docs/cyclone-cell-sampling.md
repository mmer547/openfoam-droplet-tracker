# 定常 cyclone でのセル探索修正と粒子収支

粒子142の気体速度は、修正前には同時に照会する粒子によって x 成分の符号まで変わった。修正後は同じ座標で常にセル18157を選び、(7.3263, −1.8519, −2.0056) m/s を得た。OpenFOAM v2606 の同じ座標での `cellPoint` 補間値は (7.304, −1.884, −2.029) m/s だった。

20 µm の追跡打ち切りは134個から0個になった。投入停止後2秒間の出口流出は51個から94個に増えたが、OpenFOAM の128個に対して34個少ない。100 µm では6秒までに両者とも1,024個すべてが壁に付着した。

20 µm の修正版は6秒時の浮遊が OpenFOAM より48個、壁付着が4個多く、累積流出が52個少ない。壁付着を含む装置内の残存は修正版861個、OpenFOAM 809個である。両粒径とも入口逆流・その他境界での終了は0個。0.125秒ごとの全49時刻で、投入累積数と全状態の合計が一致した。[修正前後と OpenFOAM の時系列 CSV](cyclone-cell-sampling-counts.csv)

投入停止後の20 µm の流出質量は修正前 0.2136 µg、修正後 0.3937 µg、OpenFOAM 0.5362 µg である。同じ時間帯に両コードで流出した粒子IDは17個から60個に増えた。修正後の94個中34個は本コードだけで、OpenFOAM の128個中68個は OpenFOAM だけでこの時間帯に流出した。抗力式は両者で同じであり、次の照合対象は `cellPoint` の速度補間と、セル面通過時に速度を更新する積分手順である。[改修プラン](cyclone-tracking-improvement-plan.md)

## セル探索の変更

静止メッシュに空間探索器を一つ構築する。各点について、候補セルの外接箱と、セルの各面を三角形化した閉曲面への符号付き距離で所属を確認する。最初の候補に入らない場合や面上にある場合は、その点の近傍にある候補をセル番号順に調べる。共有面は両セルで同じ頂点順から三角形化し、面上・稜線上の点は許容差内の最小セル番号に割り当てる。確定したセルの VTK 形状関数と従来の節点速度で `U` を求める。時間補間時は前後の速度場に同じ重みを使う。[実装](../track_particles.py)

追跡中に `outside` が生じた場合は、その終了点を境界パッチ全体でも判定し、内側の終了点数を `outside_inside_mesh` として出力する。この値は `outside` の内数である。

## 保存座標での検証

20 µm の旧版の軌跡から、投入時を除いた8,372点を再照会した。全点が有効となり、選択セルの外接箱から外れた点は旧版の1,068点から0点になった。全点の順序を逆にした場合、17組に分割した場合とも、有効判定と速度の全成分が元の順序と一致した。旧版が `outside` で打ち切った終了座標も、20 µm の134点、100 µm の7点すべてで流速を取得できた。

OpenFOAM の `mesh.findCell` がセルを返した8,366点のうち、8,341点でセル番号が一致した。残る25点では、両者の選んだセルはすべて面を共有する隣接セルだった。この25点から本コードが選んだセル表面までの距離は 0.0027～2.74 mm だった。残り6点では OpenFOAM の直接照会がセルを返さなかった。

## 追跡の条件

cyclone チュートリアルの形状・気流境界条件から、30,819セルで `simpleFoam` の定常 RANS 解を作成し、収束した速度場を固定した。修正前、修正後、`icoUncoupledKinematicParcelFoam` v2606 に同一の場を与えた。OpenFOAM と修正前の数値は同一条件で保存済みの比較計算から取得し、今回の修正版を新たに実行した。VTK は 9.7.2 を使用した。

粒径ごとに1,024個を 0 ≤ t < 4 s に256個/sで投入し、6 s まで追跡した。投入時刻は粒子IDを256で割った値、入口から内側への距離は0.1 mm、初速は (−10, 0, 0) m/s、時間刻みは 1/4096 s である。両者とも `sphereDrag` と浮力補正付き重力を使用した。粒子密度は 1,000 kg/m³、気体密度は 1.2 kg/m³、粘性係数は 1.8816 × 10⁻⁵ Pa·s、壁は完全付着である。[抗力モデルの比較](openfoam-v2606-comparison.md)

## 再現方法

リポジトリの回帰試験には、粒子1・10・142の時刻 2.375 s の実座標、元のセル番号3510・4662・18157・22979・22980の形状と節点速度、ゆがんだセルでの旧 `outside` 終了点を含めた。抽出した5セルでも、VTK 9.7.2 の旧一括照会では、先頭2点を加えると粒子142の x 方向流速が 7.3263 から −0.9878 m/s に変わった。共有面・稜線、入口面から内側への移動、凹多面体のくぼみ、非定常線形場での途中投入も試験する。[回帰試験](../tests/test_cell_sampling.py)・[抽出メッシュ](../tests/data/cyclone-cells.vtk)

```sh
python -m unittest discover -s tests -v
```

全粒子の追跡には定常解だけを保存したケースと共通投入座標を使う。入力の SHA-256 は `frozen/0/U` が `a0d8308adfc8e4614c018dc4113dca4be47892e0957de0b239f3bfd16d1b30fe`、`seeds.csv` が `c669070c858de8cca7bb10675874b13f8e2ee4268a165c013f77d8f700fa6770`。次は20 µm の実行例である。粒径には旧版の実行スクリプトが µm を m に換算して渡した浮動小数点値を指定した。100 µm の場合は `--diameter 9.999999999999999e-5` とし、出力ファイル名も変更する。

```sh
python track_particles.py frozen/cyclone.foam seeds.csv tracks-20.csv \
  --diameter 1.9999999999999998e-5 --drag-model sphereDrag \
  --gas-density 1.2 --gas-viscosity 1.8816e-5 --liquid-density 1000 \
  --gravity 0 0 -9.81 --initial-velocity -10 0 0 --wall walls --outlet outlet \
  --start 0 --end 6 --dt 0.000244140625 --injection-duration 4 \
  --track-interval 0.125 --flow-csv rates-20.csv --flow-interval 0.125
```
