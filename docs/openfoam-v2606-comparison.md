# OpenFOAM v2606 と本コードの液滴追跡比較

直径 100 µm の水滴を静止空気中で高さ 103 mm から落とした。時間刻み 0.5 ms では、投入から 0.35 s 後の沈降速度は OpenFOAM v2606 の `icoUncoupledKinematicParcelFoam` で **0.24403 m/s**、本コードで **0.24780 m/s** だった。本コードの方が **1.55%** 速く、床には **5.6～6.1 ms** 早く到達した。沈降速度の差は、両者が使う球形粒子の抗力相関で説明できる。

## 計算条件

| 項目 | 設定 |
|---|---|
| 実行環境 | OpenFOAM は WSL 2 の `OpenFOAM-Keysight-2606`、ビルド `_481094f-20260618`。本コードはコミット `e5057fa` の `track_particles.py` を Windows の ParaView 6.2.1 同梱 Python で実行 |
| 領域とメッシュ | 原点から 0.1 × 0.1 × 0.2 m の直方体。均等な 4 × 4 × 8 セル。底面 `floor` は z = 0、z 軸は上向き |
| 気相 | 全域で流速ゼロ。密度 1.204 kg/m³、粘性係数 1.81 × 10⁻⁵ Pa·s。OpenFOAM に与えた動粘性係数は両者の比 1.503322259 × 10⁻⁵ m²/s |
| 液滴と投入 | 直径 100 µm、密度 998.2 kg/m³ の球を1個。時刻 0 s に座標 (0.043, 0.047, 0.103) m で静止状態から投入 |
| 力と境界 | 抗力、重力 (0, 0, −9.81) m/s²、浮力補正。乱流分散・粒子間衝突は無効。全壁で完全付着 |
| 計算時間 | 0～0.48 s。両者を時間刻み 1 ms と 0.5 ms で各1回実行 |

OpenFOAM では `sphereDrag` と `gravity` を選び、速度の空間補間を `cellPoint`、速度積分を `analytical`、粒子の `maxCo` を 1 とした。投入は `manualInjection`、`nParticle 1`、壁は `localInteraction` の `stick` とした。本コードには同じメッシュと初期時刻の `U` を渡し、`--diameter 0.0001` と `--initial-velocity 0 0 0` を指定した。

## 実行結果

速度は下向きを正とし、高さは床から液滴中心までの距離とした。

| 時間刻み | 計算 | 0.35 s の沈降速度 (m/s) | 0.35 s の高さ (mm) | 床への到達時刻 (s) |
|---:|---|---:|---:|---:|
| 1 ms | OpenFOAM v2606 | 0.24403 | 23.162 | (0.4440, 0.4450] |
| 1 ms | 本コード | 0.24780 | 22.155 | 0.439408 |
| 0.5 ms | OpenFOAM v2606 | 0.24403 | 23.227 | (0.4450, 0.4455] |
| 0.5 ms | 本コード | 0.24780 | 22.160 | 0.439425 |

OpenFOAM の値は、0.35 s に保存した `lagrangian/kinematicCloud/U` と `positions` から取得した。床への到達時刻は、実行ログの `Parcel fate: patch floor` で付着数が 0 から 1 に変わった区間を示す。本コードの速度は軌跡 CSV の 0.35 s とその直前の高さから算出した区間平均で、到達時刻は `deposited,floor` 行の値である。4回とも同じ床に付着した。

## Schiller–Naumann と `sphereDrag` のモデルの違い

両モデルとも、液滴を直径 $d$ の球として扱う。気体から見た液滴の速さを $w$、球の投影面積を $A=\pi d^2/4$ とすると、抗力の大きさは $F_D=\tfrac12\rho_g A C_D w^2$ で、向きは気体と液滴の速度差を小さくする方向である。今回の計算では浮力補正込みの重力加速度 $(1-\rho_g/\rho_l)\mathbf{g}$ も共通である。

**モデルの違いは、同じ相対速度でどれだけの抗力が働くかを決める経験式にある。** 入力はどちらも粒子レイノルズ数 $Re_p=\rho_g d w/\mu_g$ である。本コードは Schiller–Naumann 相関を使う。OpenFOAM v2606 の `sphereDrag` は、公式資料が Putnam (1961) を標準モデル、Amsden ら (1989) を実装式の出典として挙げる相関を使う。今回の v2606 の標準パーセル用モデルには、Foundation v7 の `SchillerNaumannDrag` は登録されていない。[v2606 の式・出典](https://api.openfoam.com/2606/classFoam_1_1SphereDragForce.html)・[本コードの抗力計算](../track_particles.py#L299)

| モデル | 低～中 $Re_p$ での $C_D Re_p$ | 高 $Re_p$ での $C_D$ | この条件での終端速度 |
|---|---|---|---:|
| v2606 の `sphereDrag` | $24(1+Re_p^{2/3}/6)$、$Re_p\leq1000$ | 0.424 | 0.244026 m/s |
| 本コードの Schiller–Naumann | $24(1+0.15Re_p^{0.687})$、$Re_p<1000$ | 0.44 | 0.247803 m/s |

$Re_p\to0$ では両式とも $C_D Re_p\to24$ となり、同じストークス抵抗 $F_D=3\pi\mu_g d w$ に近づく。有限の $Re_p$ では補正項の係数と指数が異なり、**約 178 で抗力の大小が逆転する**。下表では粒径・気体物性を固定し、各行で同じ相対速度を両式に与えた。相対差の基準は Schiller–Naumann であり、この条件では $C_D$ の比がそのまま抗力の比になる。

| $Re_p$ | 本コードの $C_D$ | v2606 の $C_D$ | `sphereDrag` の抗力の相対差 |
|---:|---:|---:|---:|
| 1.65（今回の終端付近） | 17.623 | 17.931 | +1.74% |
| 100 | 1.092 | 1.102 | +0.92% |
| 500 | 0.5627 | 0.5520 | −1.90% |
| 2000 | 0.440 | 0.424 | −3.64% |

今回の水滴は $Re_p\approx1.6$ で終端速度に達する。この領域では同じ速さで落とすと `sphereDrag` の上向き抗力が強く、より低い沈降速度で重力と浮力の差に釣り合う。各相関から求めた終端速度は 0.35 s の計算結果と表示精度で一致する。表の **+1.74% は同じ速度での抗力差**、実行結果の **1.55% はそれぞれの終端速度の差**である。床への到達時刻には加速中の位置積分と壁到達の記録方法も影響する。

## 非定常流や出口流量の比較に使う場合

| 条件 | 実ケースでそろえる点 |
|---|---|
| 保存済みの非定常速度場 | v2606 の標準ソルバーは開始時刻に `U` を読み、静止メッシュ上でその場を使い続ける。本コードは複数の保存時刻があると前後の `U` を時間方向に線形補間する。追跡方法自体を比べるときは、まず同じ1時刻の場を両者に与える。[本コードの速度補間](../track_particles.py#L66) |
| 壁際の軌跡 | v2606 はセル面を順に追跡し、パッチごとに付着や反発を設定できる。本コードは各ステップの始点と終点を結ぶ線分が最初に外向きに横切る境界を調べ、壁で追跡を終了する。壁付着率の比較では、壁モデル、投入位置、初速、時間刻みをそろえる。[本コードの境界判定](../track_particles.py#L209) |
| 出口別の個数・質量流量 | 本コードは1追跡粒子を実液滴1個として数える。OpenFOAM のパーセルが複数の液滴を代表するときは `nParticle` で重み付けし、同じ出口・集計時間幅・終了時刻で比較する。[本コードの流量集計](../track_particles.py#L322) |

この試験で確認したのは、一様な静止空気中の単滴の沈降と床への到達である。実形状での付着率や出口流量は、流れ場、投入分布、壁条件を与えて別途評価する必要がある。
