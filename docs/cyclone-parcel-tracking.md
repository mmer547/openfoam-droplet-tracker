# v2606 のセル面追跡と定常 cyclone の最終検証

`--parcel-tracking` で OpenFOAM v2606 の `icoUncoupledKinematicParcelFoam` と同じ条件の粒子追跡を行った。定常 cyclone の2粒径・4時間刻みでは、**全92,160ステップで投入・浮遊・壁付着・出口流出の各個数が一致した**。1～6秒の各整数秒で投入済みの粒子をID別に突き合わせた延べ36,864件でも、行き先の不一致は0件だった。

## 投入停止後の残存と流出

チュートリアルの形状と気流境界条件から求めた `simpleFoam` の定常解を固定した。各粒径1,024個を同じ位置から 0 ≤ t < 4 s に256個/sで投入した。壁は完全付着、初速は (−10, 0, 0) m/s、気体密度 1.2 kg/m³、粘性係数 1.8816 × 10⁻⁵ Pa·s、粒子密度 1,000 kg/m³ である。表は両コードに共通の個数で、入口逆流・その他境界・追跡打ち切りは全条件で0個だった。定常 RANS 解のメッシュは30,819セルで、全粒子の初期位置は入口面から内側へ0.1 mm、粒子 ID i の指定投入時刻は i/256 s である。

| 粒径 | 刻み（s） | 6秒時の浮遊 | 壁付着 | 累積出口流出 | 停止後2秒間の出口流出 |
|---|---:|---:|---:|---:|---:|
| 20 µm | 1/512 | 310 | 629 | 85 | 59 |
| 20 µm | 1/1024 | 307 | 534 | 183 | 103 |
| 20 µm | 1/2048 | 285 | 527 | 212 | 128 |
| 20 µm | 1/4096 | 291 | 518 | 215 | 128 |
| 100 µm | 上記4刻みの各計算 | 0 | 1,024 | 0 | 0 |

20 µm・1/4096 s では、投入停止時に浮遊585個・壁付着352個・累積流出87個、2秒後の装置内残存は浮遊と付着を合わせて809個だった。停止後に出口を通った128個はすべて両者で同じIDだった。100 µm では停止時に26個が浮遊し、6秒までにすべて付着した（同じ最小刻み）。時間刻みに伴う20 µm の収支変化も両者で再現した。[0.125秒ごとの時系列](../validation/cyclone-parcel-inventory.csv)・[条件別の検証集計](../validation/cyclone-parcel-validation.csv)

## 取り除いた差

1. **補間と所属四面体**　OpenFOAM が書き出したセル中心・節点の速度を使用する。粒子ごとに所属四面体と4個の重心座標を保持し、面を通ると隣接四面体へ引き継ぐ。v2606 の直接評価と保存座標9,396点で照合した。共通有効9,390点の所属セルと四面体はすべて一致し、速度ベクトル差は最大 6.06 × 10⁻¹⁵ m/s だった。残り6点は両者とも領域外と判定した。
2. **移動と抗力更新の順序**　現在の粒子速度で直線移動し、次のセル面かサブステップ終端で、到達点の気体速度を使って `sphereDrag` と浮力補正付き重力を積分する。同一セル内の四面体境界では座標だけを引き継ぐ。`maxCo = 1` と v2606 のセル体積から移動上限を求める。外部面は最初に外向きに通過した時点でパッチと時刻を確定する。[追跡・速度更新の実装](../parcel_tracking.py)
3. **投入直後のステップ**　v2606 の `InjectionModel::inject` は新規粒子を一度移動させる。その後 `Cloud::move` が全粒子のステップ割合をリセットし、雲全体を移動させる。比較モードはこの順序も再現する。今回の格子時刻上の投入では、例えば粒子0が時刻1秒で持つ年齢は OpenFOAM の保存値で 1.000244140625 s（刻み 1/4096 s）だった。同一ステップに複数個を投入する場合、v2606 の投入処理に合わせてステップ内の投入時刻を配分する。CSV の境界通過時刻は、その粒子の投入時刻以降に記録する。

`--cell-point` のみの段階では、20 µm・最小刻みの停止後流出が71個、浮遊301個、壁付着593個だった。今回の変更は抗力式を保ったまま、これらを v2606 の128個、291個、518個にそろえた。毎秒の保存位置も、対応する浮遊・付着粒子35,315件で距離の差が最大 1.57 × 10⁻¹² m 未満だった。比較値には OpenFOAM の ASCII 保存時の丸めを含む。

## 単滴沈降と回帰試験

静止空気中で高さ103 mmから100 µm の水滴を放した。0.35 s の高さは、刻み1 msで両者とも23.16170023 mm、0.5 msで23.22703780 mm。沈降速度はともに0.244026 m/sだった。本コードの床到達時刻はそれぞれ 0.44491496 s と 0.44518271 s で、v2606 の付着記録区間 (0.444, 0.445] s、(0.4450, 0.4455] s に入った。単滴試験の粒子密度は998.2 kg/m³、気体密度は1.204 kg/m³、粘性係数は1.81 × 10⁻⁵ Pa·s である。同じ物性で既定の Schiller–Naumann を使った場合の沈降速度は0.24780 m/s だった。[抗力相関の式と既定値](../README.md#液滴に働く力)

自動試験では、入口面からの出発、複数セルの横断、稜線を含む移動、斜めの壁衝突、途中ステップ、到達時の速度更新を確認する。Windows の ParaView 6.2.1 同梱 Python による20 µm・最小刻みの単回計測では、同一入力・保存間隔で第2段階は44.4秒・ピークワーキングセット349 MiB、セル面追跡は24.7秒・504 MiBだった。セル面追跡は初期化時に四面体の隣接表を保持する。[回帰試験](../tests/test_parcel_tracking.py)

## 再現方法と対象範囲

参照環境は WSL 2 の OpenFOAM v2606（倍精度、ビルド `_481094f-20260618`）と VTK 9.7.2。使用した `frozen/0/U` の SHA-256 は `a0d8308adfc8e4614c018dc4113dca4be47892e0957de0b239f3bfd16d1b30fe`、`seeds.csv` は `c669070c858de8cca7bb10675874b13f8e2ee4268a165c013f77d8f700fa6770` である。

比較モードの対象は、静止した3次元の再構築済みメッシュ、正体積の四面体分割、1時刻の固定気流場、一定物性の球形粒子、一方向連成、乱流分散・粒子衝突なし、完全付着壁と流出パッチである。通常モードは既定の Schiller–Naumann を使用する。`--parcel-tracking` は比較用の `cellPoint`、`sphereDrag`、解析的な速度更新、`maxCo = 1` をまとめて選択する。

1. WSL の v2606 環境で、リポジトリのルートから `wmake tools/exportCellPoint` を実行する。固定場ケースに対し `exportCellPoint -case frozen` を実行し、`postProcessing/trackerCellPoint/volumes.dat` を含む出力を作る。旧版の出力がある場合は、別名へ退避してから再生成する。
2. 次の例で本コードを実行する。参照用 OpenFOAM ケースは同じメッシュ・場・物性・投入列を使い、`U cellPoint`、`U analytical`、`sphereDrag`、`gravity`、`maxCo 1`、壁 `stick`、出口 `escape` とする。

```bash
python track_particles.py frozen/cyclone.foam seeds.csv parcel-20.csv \
  --parcel-tracking --diameter 1.9999999999999998e-5 \
  --gas-density 1.2 --gas-viscosity 1.8816e-5 --liquid-density 1000 \
  --gravity 0 0 -9.81 --initial-velocity -10 0 0 --wall walls --outlet outlet \
  --start 0 --end 6 --dt 0.000244140625 --injection-duration 4 \
  --track-interval 0.125 --flow-csv parcel-rates-20.csv --flow-interval 0.125
```

OpenFOAM のログと、毎秒の ASCII `origId`、`active`、`positions` を保存した参照ケースで、収支と粒子別の結果を再照合できる。

```bash
python tools/check_parcel_run.py parcel-20.csv log.icoUncoupledKinematicParcelFoam reference-case
python -m unittest discover -s tests -v
```
