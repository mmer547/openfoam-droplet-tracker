# OpenFOAM 後処理による液滴追跡 — 技術ドキュメント

[track_particles.py](./track_particles.py) は、OpenFOAM で保存した気体速度場 `U` を読み、個々の液滴の位置と速度を時間積分する Python スクリプトです。同じ流れ場を使って液滴径や投入位置を変え、出口への到達時間や壁への付着率を比較できます。静止した再構築済みメッシュを使い、液滴から気体への運動量のフィードバックを無視できる希薄な条件を想定します。

## 100 µm の水滴を 10,000 個投入する

Python 環境に `python -m pip install numpy vtk` で依存ライブラリを入れます。ケースディレクトリで次を実行します。例は z 軸上向き、開始時刻 0 s、終了時刻 1 s です。パッチ名は実ケースの `constant/polyMesh/boundary` に合わせます。

```bash
touch case.foam
python /workspace/track_particles.py case.foam tracks.vtp \
  --patch inlet --count 10000 --seed 42 --outlet outlet \
  --diameter 1e-4 --gravity 0 0 -9.81 \
  --start 0 --end 1 --dt 0.001
```

`--patch` と `--count` で開始時刻に一括投入します。投入位置は面積あたり一様で、入口速度や流量による重み付けはありません。同じメッシュと乱数種 `--seed` を使うと投入位置を再現できます。任意の位置を使う場合は、ヘッダーが `x,y,z`、座標単位が m の CSV を用意します。出力先には新しいファイル名を指定します。

```bash
python /workspace/track_particles.py case.foam seeds.csv tracks.csv \
  --diameter 1e-4 --outlet outlet --end 1 --dt 0.001
```

## 追跡モードの選び方

| 目的 | オプション | 気体速度の補間と粒子の移動 |
|---|---|---|
| 保存した気流場で液滴を追跡する | `--diameter d` | VTK の節点速度を補間し、ステップ内の気体速度と抗力係数を固定して位置・速度を積分する。既定の抗力は Schiller–Naumann |
| 抗力相関だけを v2606 に合わせる | `--diameter d --drag-model sphereDrag` | 通常の補間・時間積分で v2606 の球形粒子用抗力を使う |
| 気体速度の補間を v2606 に合わせる | `--cell-point` | セル中心と面の3頂点の速度を四面体の重心座標で補間する。複数の保存時刻では前後の速度場を時間方向に線形補間する |
| `icoUncoupledKinematicParcelFoam` v2606 の粒子追跡を再現する | `--parcel-tracking --diameter d` | 1時刻の固定場で `cellPoint`、`sphereDrag`、解析的な速度更新、`maxCo = 1` を使用する。現在の粒子速度でセル面まで移動し、到達点の気体速度で粒子速度を更新する |

通常モードでは `--cell-cache-size 2048` のように、形状をメモリに保持するセル数の上限を指定できます。既定は1,024セルです。粒子が同じセルを繰り返し通る計算では、上限を増やすと形状の再構築を減らせます。必要なメモリは保持するセルの数と形状に依存します。この設定は通常モードの VTK 補間に適用されます。

`--cell-point` と `--parcel-tracking` には、v2606 のエクスポーターで出力した四面体、境界面、節点・セル中心の速度が必要です。セル面追跡にはセル体積も使います。WSL でリポジトリのルートから次を実行します。`frozen` は再構築済みの固定場ケースです。

```bash
source /usr/lib/openfoam/openfoam2606/etc/bashrc
wmake tools/exportCellPoint
exportCellPoint -case frozen
```

出力先はケース内の `postProcessing/trackerCellPoint` です。ケース更新後に再生成するときは、既存の出力を先に退避します。補間値を直接照合する場合は、初回のエクスポートに `-samplePoints coordinates.dat` を加えます。このファイルは1行に1点、空白区切りの x y z 座標（m）を記載します。

```bash
python tools/check_cell_point.py frozen/cyclone.foam coordinates.dat --time 0
```

粒子追跡全体の実行例、投入停止後の残存・流出、適用範囲は[最終検証レポート](docs/cyclone-parcel-tracking.md)にまとめています。

## 液滴に働く力

液滴中心の位置を **x**、液滴速度を **v**、その位置での気体速度を **U** とします。相対速度 **w** = **U** − **v** を使うと、抗力は液滴を気体速度に近づける向きに働きます。体積を $V=\pi d^3/6$、投影面積を $A=\pi d^2/4$、質量を $m=\rho_l V$ とすると、運動方程式は次のとおりです。

$$
\frac{d\mathbf{x}}{dt}=\mathbf{v},\qquad
m\frac{d\mathbf{v}}{dt}
=\underbrace{\tfrac12\rho_g C_D A |\mathbf{w}|\mathbf{w}}_{\text{抗力}}
+\underbrace{m\mathbf{g}}_{\text{重力}}
+\underbrace{(-\rho_g V\mathbf{g})}_{\text{浮力}} .
$$

浮力は重力と逆向きです。重力と浮力を合わせた加速度は $\mathbf{g}_{\rm eff}=(1-\rho_g/\rho_l)\mathbf{g}$ になります。

| 物理量 | オプション | 液滴モデルの既定値 |
|---|---|---|
| 液滴直径 $d$ | `--diameter` | m 単位で指定。100 µm は `1e-4` |
| 液滴密度 $\rho_l$ | `--liquid-density` | 998.2 kg/m³ |
| 気体密度 $\rho_g$ | `--gas-density` | 1.204 kg/m³ |
| 気体の粘性係数 $\mu_g$ | `--gas-viscosity` | 1.81 × 10⁻⁵ Pa·s（動粘性係数 ν とは単位が異なる） |
| 重力加速度 **g** | `--gravity` | (0, 0, −9.81) m/s² |
| 液滴初速 **v** | `--initial-velocity` | 投入位置での **U**。指定時は全液滴に共通の 3 成分（m/s） |

**抗力係数。** 粒子レイノルズ数 $Re_p=\rho_g d |\mathbf{w}|/\mu_g$ から、各液滴の抗力係数を毎ステップ更新します。既定の Schiller–Naumann 相関では、$0<Re_p<1000$ で $C_D=(24/Re_p)(1+0.15 Re_p^{0.687})$、$Re_p\ge1000$ で $C_D=0.44$ を使います。

両モデルの違いは、同じ相対速度に対する抗力を決める経験式です。比較検証用の `sphereDrag` では $0<Re_p\le1000$ で $C_D=(24/Re_p)(1+Re_p^{2/3}/6)$、$Re_p>1000$ で $C_D=0.424$ を使います。

**コード内の表現。** `droplet_relaxation` は $f=C_D Re_p/24$ とし、有効緩和時間 $\tau=\rho_l d^2/(18\mu_g f)$ を返します。抗力加速度は **w** / τ です。低 $Re_p$ で $f$ は 1 に近づき、ストークス抵抗になります。相対速度ゼロでは $f=1$、抗力ゼロから計算を開始できます。

**計算値の目安。** 表の既定物性で、直径 100 µm の水滴が静止空気中を落下すると、抗力が浮力込みの重力と釣り合う終端速度は Schiller–Naumann で約 **0.248 m/s**（$Re_p\approx1.65$）、`sphereDrag` で約 **0.244 m/s**（下向き）です。これは抗力式から得られる基準値で、実験値との照合は別途必要です。

液滴は直径・密度が一定の球形点粒子として扱い、気体物性も一定です。蒸発、変形・分裂、液滴同士の衝突、揚力、未解像の乱流によるランダムな分散はモデルの対象外です。壁への到達判定には液滴中心を使います。

## 通常モードの処理と時間積分

| 順序 | 関数・クラス | 処理 |
|---|---|---|
| 1 | `CellSampler`、`Flow.sample` | 静止メッシュの各粒子について候補セルの三角形表面で内外を判定し、VTK の節点 `U` を所属セルの形状関数で補間。非定常場では前後2時刻に同じ空間重みを使い、時間方向に線形補間 |
| 2 | `Flow.boundary_surfaces`、`sample_surface` | パッチを三角形に分割。面積比例で三角形を選び、その内部に一様乱数で初期位置を生成 |
| 3 | `run`、`droplet_relaxation`、`relaxation_step` | 追跡中の粒子をまとめて計算。各粒子のステップ開始時の **U** と τ から、次の速度と仮の終点を計算 |
| 4 | `Boundaries.hits` | 静止メッシュの境界三角形を覆う格子を事前計算し、両端が同じ空き格子にある線分を除外。残りの線分と境界三角形の交差を探索。外向きに横切る最初の面で追跡を終了。投入面から内向きに出発できる |
| 5 | `trajectory_output` | 初期点、各ステップの位置、終了点を粒子 ID とともに記録。CSV は逐次書き込み、VTK は全軌跡をメモリに蓄えて折れ線として出力 |

**時間積分。** ステップ幅 $h$ の間、**U** と τ を固定します。$z=h/\tau$、$G=1-e^{-z}$、$\Delta\mathbf{v}=\mathbf{U}-\mathbf{v}_n+\tau\mathbf{g}_{\rm eff}$ と置くと、コードの更新式は次のようになります。

$$
\mathbf{v}_{n+1}=\mathbf{v}_n+G\Delta\mathbf{v},\qquad
\mathbf{x}_{n+1}=\mathbf{x}_n+h\left[\mathbf{v}_n+(1-G/z)\Delta\mathbf{v}\right].
$$

この式はステップ内の係数を固定した運動方程式の解析解です。流速の空間変化や非線形抗力の変化、境界付近での軌道の曲がりは刻み幅に依存します。付着率を比較する場合は、同じ乱数種で `--dt` を半分にし、付着率と到達時刻の変化を確認できます。保存時刻が 1 つなら定常流として追跡でき、複数ある場合は保存された時間範囲内で追跡します。`--start` の既定値は最初の保存時刻です。

**他の計算モード。** `--tau` に正の秒数を指定すると、一定緩和時間モデルで計算します。このモードの `--gravity` は直接与える有効加速度で、既定値はゼロです。`--tau` と `--diameter` は排他です。両方を省略すると流体トレーサーとなり、各ステップで **x** を $h\mathbf{U}$ だけ進めます。

## 境界と出力の読み方

ParaView で `.vtp` または `.vtk` を開くと粒子ごとに 1 本の軌跡が表示されます。`time` は各点の時刻（s）、`particle_id` は投入時に割り当てた ID です。CSV では各行が 1 粒子の 1 記録点に対応します。

| CSV の状態 | VTK の `status` | 意味 |
|---|---:|---|
| `active` | 0 | 初期点、またはその時刻に追跡中の点 |
| `deposited` | 1 | 壁で完全付着。中心が壁と交差した点で終了 |
| `escaped` | 2 | 指定した出口と交差し、流出として終了 |
| `boundary` | 3 | その他の境界と交差して終了。周期境界や対称境界も自動通過・反射しない |
| `outside` | 4 | 境界との交点を得ず、仮の終点で流速を取得できずに終了 |

`outside` が生じた場合、終了点のうち境界パッチ全体の閉曲面の内側にある個数を `outside_inside_mesh` に表示します。境界が閉じていない場合は `unknown` を表示します。

`type wall` の壁は自動検出します。壁を追加する場合は `--wall 名前`、出口は `--outlet 名前` で指定します。どちらも複数回指定できます。境界到達時刻は、移動線分上の交点までの距離割合を使ってステップ内で線形補間します。CSV の `patch` に到達パッチ名、VTK の `patch_id` にその番号が入ります。番号と名前の対応はフィールドデータ `patch_names` にあります。パッチ未到達の点では CSV は空欄、VTK は −1 です。

**付着率の集計例。** 計算終了時刻までの個数基準の付着率は、最終状態が `deposited` の粒子 ID 数を総投入数で割ります。例えば 10,000 個のうち 213 個が付着した場合は 2.13% です。終了時刻に `active` の粒子はまだ領域内にいるので、終了時刻も併記すると結果を比較できます。

## 投入流量と出口通過流量

軌跡の出力に `--flow-csv flow.csv --flow-interval 0.1` を追加すると、開始時刻から 0.1 s ごとの個数と区間平均流量を別ファイルに出力します。集計幅の既定値は `--dt` です。各区間は左端を含み、最終区間のみ右端も含みます。端数の区間では実際の区間長を使います。

| CSV 列 | 意味 |
|---|---|
| `start_s`, `end_s` | 集計区間の開始・終了時刻（s） |
| `stream`, `patch` | `injected` は投入、`outlet` は指定出口ごと、`outlet_total` は全指定出口の合計。CSV 座標投入時の投入パッチ欄は空欄 |
| `count`, `cumulative_count` | 区間内の液滴数、開始からの累積数 |
| `number_per_s` | 区間内の個数 ÷ 区間長（個/s） |
| `volume_m3_per_s`, `mass_kg_per_s` | 個数流量に液滴 1 個の体積 πd³/6、さらに液体密度を掛けた体積流量と質量流量。`--diameter` 省略時は両列とも空欄 |

1 追跡粒子を実液滴 1 個として数えます。既定の一括投入では投入数の全量が最初の区間に入り、平均投入流量は集計幅に依存します。出口では指定したパッチとの交点の補間時刻を使い、外向きの通過を粒子ごとに 1 回だけ数えます。時間内に通過がない区間も 0 で出力します。測定する出口は `--outlet 名前` でそれぞれ指定してください。

## 軌跡の保存を減らして高速化する

軌跡と流量の両方が必要な場合は、通常のコマンドに `--track-interval 0.01` を追加します。`--dt 0.001` なら 10 ステップごとに位置を保存します。投入点、付着・流出などの終了点、計算終了時に残っている粒子の最終点も記録します。保存間隔が刻みの整数倍でない場合は、各予定時刻に達した最初のステップの位置を使います。省略時は毎ステップ保存します。

流量だけを集計するときは、位置引数の出力先に流量 CSV を指定します。

```bash
python /workspace/track_particles.py case.foam flow.csv --flow-only \
  --patch inlet --count 10000 --seed 42 --outlet outlet \
  --diameter 1e-4 --dt 0.001 --end 1 --flow-interval 0.1
```

どちらのモードも液滴の積分、境界判定、出口通過時刻の計算は毎ステップ行います。`--flow-interval` は流量 CSV の集計幅です。

## 投入停止後の粒子を追跡する

次の例は 0 s から 2 s の間に合計 10,000 個（平均 5,000 個/s）を投入し、10 s まで追跡します。保存済みの非定常場を使う場合は、追跡終了までの流速場が必要です。出口名は実ケースのパッチ名に置き換えます。

```bash
python /workspace/track_particles.py case.foam tracks.vtp \
  --patch inlet --count 10000 --seed 42 --diameter 1e-4 \
  --start 0 --injection-duration 2 --end 10 --dt 0.001 \
  --outlet outletA --outlet outletB --track-interval 0.05 \
  --flow-csv flow.csv --flow-interval 0.1
```

通常モードでは、総数 N、投入時間 T に対し、粒子 ID i の投入時刻は `start + i × T / N`（i = 0 … N−1）です。非定常場では各投入時刻の流速を補間し、途中で投入した粒子はそのステップの残り時間だけ進めます。CSV で位置を指定した場合は行順で投入します。T の既定値は 0（一括投入）です。時間指定は流量のみのモードにも適用できます。

終了区間の流量 CSV で、対象パッチ（例では `outletA`）の累積通過個数を `injected` の累積個数で割ると、その時刻までにその出口を通過した粒子の割合が得られます。時間指定投入の実行後には、投入総数、領域内に残った粒子数（`active`）、状態別の終了数を表示します。
